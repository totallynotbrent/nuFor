# 3D state, grid, EOS

The jump to three dimensions is the first genuinely volumetric milestone: every
field gains a third velocity and a third momentum component, and the grid gains
a depth axis. This page covers the foundations -- the structured 3D grid, the
5-component conserved state, and the 3D ideal-gas relations -- that the solver
milestone builds on.

## The grid

`Grid3d` is a uniform structured Cartesian grid over a box, with `nx * ny * nz`
cells. Arrays are flat and row-major with x varying fastest:

    index(i, j, k) = (k * ny + j) * nx + i

so the three center-coordinate vectors and the {nx+1, ny+1, nz+1} face planes
follow the same ordering as their 2D counterparts.

## The state

`ConservedState3d` is structure-of-arrays, one flat vector per variable, five
in all:

    (rho, rho u, rho v, rho w, rho e_t)

Three velocity components means the kinetic energy term gains a `w^2` -- nothing
else about the structure changes. Conversions (`prim_to_cons3d` /
`cons_to_prim3d`) reject non-positive density and round-trip exactly, exactly
like the 2D versions.

## The EOS

Pressure, sound speed, and Mach number extend the 2D forms by the third
velocity component:

    p     = (gamma - 1) rho (e_t - (u^2 + v^2 + w^2)/2)
    a     = sqrt(gamma p / rho)
    M     = |v| / a

## Tests

`tests/3d.rs` checks the grid geometry ((2,3,4) box, centers, faces, flat-index
order), the state round-trip and the zero-density guard, and the EOS pressure /
sound-speed / Mach values against hand-computed numbers.
