# nuFor documentation

The engineering constitution lives in `nuFor_README.md` at the repository root.
This directory holds living documentation that grows with the implementation.

| Directory | Contents |
|-----------|----------|
| `architecture/` | Module boundaries, FFI design, data flow |
| `numerics/` | Numerical methods as implemented (fluxes, reconstruction, time stepping) |
| `physics/` | Physical models and their equations of state |
| `formats/` | Case schema, output/restart formats |
| `research/` | Durable research notes (method decisions, evidence, alternatives) |
| `verification/` | Verification cases, expected results, error norms |
| `operations/` | Build, install, benchmark, and deployment notes |

Write the change's documentation in the same commit as the change.
